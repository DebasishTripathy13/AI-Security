10 principles to weave into every answer

#PrincipleWhy
1The LLM is not a security boundaryEnforce authorization and business rules in deterministic code. The model proposes and code decides.
2Everything in context is untrustedDocs, web, email, tool results, memory and other agents can all carry instructions.
3Design for containmentPrompt injection has no complete fix, so limit what a hijacked model can reach.
4Least privilege, least agencyMinimal tools, scopes and autonomy; user-scoped, short-lived tokens.
5Risk-tiered human approvalIrreversible or external actions need approval that shows the exact action. Watch for fatigue.
6Output is untrusted inputEncode, validate and parameterize. Never eval.
7Break the lethal trifectaNever combine private data, untrusted content and external communication without a human.
8Layered guardrails, fail closedInput, context, output and action rails, logged and tuned on real traffic.
9Models and tools are supply chainProvenance, signing, pinning, scanning, AI-BOM, MCP registries.
10Measure continuouslyEvals in CI with ASR, utility and over-refusal; red teaming; production monitoring.

The CATCH framework for scenario questions

C · ClarifyWhat does it do? Users, data, autonomy, actions.
A · ArchitectureDraw components, data flows and trust boundaries.
T · ThreatsOWASP LLM/Agentic + STRIDE per boundary; ATLAS.
C · ControlsDeterministic first, then guardrails; prevent → detect → respond.
H · How we verifyEval harness + red team, metrics, monitoring, owner.
Sample opener"Before talking about controls, I'd like to understand what this assistant can actually do, because the risk comes from its tools and data access. Then I'll draw the data flow, mark where untrusted content enters, go through the OWASP LLM and Agentic risks at each boundary, propose layered controls, and say how I'd measure that they work."

Glossary

TermMeaning
Prompt injection (direct / indirect)Input that overrides intended behavior. Indirect comes from processed content; Microsoft calls it XPIA.
JailbreakBypassing the model's safety training (a form of prompt injection).
GuardrailA runtime control on inputs, context, outputs or actions, either deterministic or classifier-based.
MiddlewareCode wrapping a model or tool call that can inspect, modify, block or log it.
Agent harnessThe runtime around a model: loop, context, tools, permissions, hooks, sandbox, telemetry.
Eval harnessThe framework that runs datasets against a system, scores outputs and aggregates metrics.
ASRAttack success rate: successful attacks divided by attempts.
Over-refusalWrongly refusing benign requests. It's the usability cost of safety.
pass@k / pass^kAt least one success in k tries / all k tries succeed (reliability).
MCP / A2AProtocols for agent ↔ tool and agent ↔ agent connections.
SpotlightingMarking untrusted text (delimiters, datamarking, encoding) so the model treats it as data.
AI-BOMBill of materials for models, datasets, adapters, tools and prompts.
