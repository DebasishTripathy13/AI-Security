Module 05 · Adversary TTPs

MITRE ATLAS

Adversarial Threat Landscape for Artificial-Intelligence Systems: a knowledge base of real adversary tactics, techniques and case studies against AI, modeled on MITRE ATT&CK. OWASP tells you which risks exist. ATLAS tells you how attackers actually carry them out.

⏱ 30 minPriority ★★★Verified against ATLAS data v5.6.0
Key takeaways
  • 16 tactics, two of them AI-specific: AI Model Access and AI Attack Staging.
  • Know about 15 technique IDs, e.g. T0051 prompt injection, T0054 jailbreak, T0070 RAG poisoning, T0053 agent tool invocation.
  • Case studies prove realism: Slack AI, M365 Copilot, ShadowRay, PoisonGPT, postmark-mcp.
  • Use it for threat modeling, red-team planning, detection mapping and coverage heatmaps.

What ATLAS is

Origin and scope

  • Grew out of the Adversarial ML Threat Matrix (Oct 2020), a collaboration led by MITRE and Microsoft with a dozen other organizations. It became ATLAS in 2021.
  • Covers predictive ML (evasion, poisoning, extraction) and GenAI/LLMs and, since 2025, a fast-growing set of AI agent techniques (tool invocation, context poisoning, MCP/tool supply chain).
  • Grounded in case studies: real incidents and red-team exercises, each mapped step by step to techniques.

By the numbers (data v5.6.0)

  • 16 tactics (AML.TAxxxx)
  • ~100 techniques + ~70 sub-techniques (AML.Txxxx[.yyy])
  • 35 mitigations (AML.Mxxxx)
  • 57 case studies (AML.CSxxxx)
  • Counts grow with every release, and names moved from "ML" to "AI" in 2025 (e.g. "ML Model Access" became "AI Model Access"). Say "around" in interviews.

Tactic

The adversary's goal at a step: the why. Example: Exfiltration.

Technique / sub-technique

How the goal is achieved. Example: AML.T0024.002 Extract AI Model.

Mitigation & case study

Defenses mapped to techniques (e.g. AML.M0004 Restrict Number of AI Model Queries) and real-world procedures.

Companion tools: the ATLAS Navigator (matrix visualization and layer annotation, like ATT&CK Navigator), Arsenal (a CALDERA plugin for automated adversary emulation against AI), and MITRE's AI Incident Sharing initiative for anonymized incident data.

Say this"ATLAS reuses most of ATT&CK's tactics and adds two AI-specific ones. AI Model Access is how the adversary gets to the model: an inference API, an AI-enabled product, physical access, or full white-box access. AI Attack Staging is where they prepare the AI-specific attack: building proxy models, crafting adversarial data, inserting backdoor triggers, and verifying the attack works before using it."

Worked examples: real case studies mapped to tactics

1 · Slack AI data exfiltration (AML.CS0035, Aug 2024)

Resource DevT0066 Retrieval Content Crafting + T0065 Prompt Crafting
Initial AccessT0012 Valid Accounts (ordinary workspace user)
AI Model AccessT0047 AI-enabled product (Slack AI)
PersistenceT0070 RAG Poisoning (message in public channel)
ExecutionT0051.001 Indirect prompt injection on victim's query
Credential AccessT0082 RAG Credential Harvesting (API key in private channel)
ExfiltrationT0077 LLM Response Rendering (key in a clickable link)

Breaks the chain: M0030 (don't let untrusted content steer actions), output link restrictions, separating public and private channel contexts, M0024 telemetry.

2 · Financial transaction hijacking with M365 Copilot (AML.CS0026, 2024)

ReconT0064 Gather RAG-indexed targets (Copilot indexes inbox email)
DiscoveryT0069 Discover system info (delimiters, instruction keywords)
Resource DevT0066 + T0065 crafted retrievable email
Initial AccessT0093 Prompt infiltration via email
Defense EvasionT0068 Obfuscation; T0071 false RAG entry; T0067.000 fake citations
ExecutionT0051.001 Indirect injection; T0053 tool invocation
ImpactT0048.000 Financial harm (fraudulent bank details)

3 · ShadowRay (AML.CS0023, 2023–24)

ReconT0006 Active scanning for exposed Ray dashboards
Initial AccessT0049 Exploit public-facing app (unauthenticated Jobs API)
CollectionT0035 AI artifact collection (models, data)
Credential AccessT0055 Unsecured credentials (SSH, cloud, HF tokens)
ExfiltrationT0025 via cyber means
ImpactT0048.000 Financial harm (crypto-mining on GPUs)

Lesson: most AI breaches start with classic infrastructure flaws. The lesson is network exposure and missing auth, not anything exotic about models.

4 · PoisonGPT (AML.CS0019, 2023)

ImpactT0031 Erode integrity; T0048.001 reputational harm

How to use ATLAS in practice

Threat modeling

For each component in your DFD, ask which ATLAS techniques apply. Use Navigator layers to mark "relevant / mitigated / gap".

Red team planning

Build adversary emulation plans from case studies, e.g. "replicate CS0035 against our Slack-like assistant". Report findings with technique IDs.

Detection engineering

Map telemetry to techniques: prompt-injection classifier hits → T0051; abnormal query volume → T0024/T0034; tool calls after retrieval → T0053/T0086; new model hashes → T0010.

Gap analysis & reporting

Show leadership a coverage heatmap of mitigations (M00xx) against the techniques relevant to your systems. Prioritize techniques with real case studies.
